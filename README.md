# Manikandan B — Portfolio V2

A responsive, interactive GitHub Pages portfolio built with semantic HTML, modern CSS and vanilla JavaScript.

## Improvements in V2

- Fixed desktop header with responsive mobile drawer
- Interactive hero technology modules and backend architecture map
- Responsive layouts for desktop, tablet and mobile
- Scroll-aware active navigation and right-side section progress
- Animated background data field and reveal transitions
- Interactive technology map
- Pointer-reactive project cards
- Accessibility support and reduced-motion handling
- Uses the supplied profile portrait and resume

## Preview locally

```bash
python3 -m http.server 8080
```

Open http://localhost:8080

## Deploy to GitHub Pages

Create the repository `manibg.github.io`, copy the contents of this folder into it, commit and push to the `main` branch. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.

Your site will be available at `https://manibg.github.io/`.
